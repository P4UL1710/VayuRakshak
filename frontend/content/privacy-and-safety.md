# Privacy and user control
Preferences, approvals, device schedules, calendar suggestions and chat remain in session memory and reset on refresh. Guide-only preferences (mute, optional narration, idle help and completed tour) are stored locally; guide progress and dismissal use session storage. Sensitive chat, health data and credentials are not saved in browser storage. Chat input is sent to the site’s own API when submitted. No third-party AI model receives guide questions in the default local retriever.

The guide answers only from controlled website documentation with source links. Unknown questions get a verified-answer fallback. Narration never starts on idle or chat arrival. Listen or Start with audio explicitly starts speech; browser speech synthesis is labelled as a browser fallback and may use a browser/vendor speech service. Optional Edge TTS sends the selected guide text through a configured server provider; the endpoint rejects text outside curated guide narration. Do not put personal information into narration.

Disconnect integrations anytime. Delete mock data clears personal session state; clear guide preferences separately. Credentials remain server-side. No purchases, unsolicited messages, automatic calendar edits or device actions before approval.
